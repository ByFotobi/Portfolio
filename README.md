# Portfolio OnePager

Ein einfacher statischer Portfolio-OnePager für GitHub Pages.

## Anpassen

1. Öffne `index.html`.
2. Ersetze `Max Mustermann`, `max@example.com` und die Projekttexte durch deine Daten.
3. Passe Links zu GitHub, LinkedIn und Projekten an.
4. Optional: Ersetze `assets/profile-card.svg` durch ein eigenes Bild.

## Lokal ansehen

Öffne `index.html` direkt im Browser.

## Auf GitHub Pages veröffentlichen

1. Neues Repository auf GitHub erstellen, zum Beispiel `portfolio`.
2. Diese Dateien ins Repository pushen.
3. In GitHub unter `Settings` → `Pages` als Source `Deploy from a branch` wählen.
4. Branch `main` und Ordner `/root` auswählen.
5. Die Seite ist danach unter `https://DEIN-NAME.github.io/portfolio/` erreichbar.

Wenn dein Repository `DEIN-NAME.github.io` heißt, liegt die Seite direkt unter
`https://DEIN-NAME.github.io/`.
